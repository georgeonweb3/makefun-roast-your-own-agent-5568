One line, at most 140 characters, roasting my own AI agent: it has a 200k-token context window, forgot my name by token 40, and spent the rest confidently calling me "boss". Confident wrong answers plus eager agreement — the two classic agent behaviours, in one line.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `ENTRY_OUTPUT`).
